# Seismic, proof before the patch

1. **The blind spot**: similarity finds nearby text while a dependency path stays hidden.
2. **Build the graph**: a repository becomes an immutable HydraDB snapshot with typed code edges.
3. **See the blast radius**: a real diff against Seismic itself expands `_bounded_int` to three supported impacts, a required transport test and the `seismic-http` entrypoint.
4. **Abstain honestly**: an unresolved symbol returns zero, not a confident guess.
5. **Give agents a gate**: send a unified diff through stateless MCP and return a review decision, required test, affected entrypoint and exact path.
6. **Learn across snapshots**: incidents attach to stable identities and native path procedures do the traversal.
7. **Show the receipts**: report the exact test split, graph-versus-TF-IDF comparison, self-authored smoke, three-repository portability proof and local stress proof.

All scenes are rebuilt as editable Remotion components. There are no generated images and no subtitle captions.
