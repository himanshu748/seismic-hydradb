# Seismic launch demo

- Product: Seismic, graph-native blast radius analysis for coding agents
- Audience: Hack Hydra Track 02B judges and technical builders
- Goal: Prove the product is real, graph-native and useful before an agent edits code
- Format: 1920x1080 landscape, under three minutes
- Style: graphite, survey paper, hazard orange and instrument green from `docs/design.md`
- Visual source: Remotion React components that reproduce the real graph, dashboard and MCP output
- Captions: none
- Claims: only checked-in test, evaluation and stress evidence
- Narration: concise technical voiceover, never an official benchmark claim
